nbview

Read Jupyter notebooks from any GitHub repo.

nbview is a fast nbviewer alternative that runs entirely in your browser, so there is no server to go down. Paste a GitHub repo, notebook link, gist or nbviewer link, or change nbviewer.org to nbview.org in the address bar and the same notebook opens here. Private repos work when you sign in or add a read-only token from the top bar.

nbview is an independent project and is not affiliated with Project Jupyter or nbviewer.

Private repos

Signing in grants read access to all your repositories, because a classic sign-in has no per-repository option. For least privilege, use a fine-grained token below instead.

To open notebooks from private repos, use a fine-grained token with Contents: Read-only access to those repos. A classic token with no scopes works for public repos and raises the folder-browsing limit.

Folder browsing allows 60 requests an hour without a token and 5,000 with one; opening public notebooks does not use that limit. The token is stored in this browser only and sent only to api.github.com. The privacy page lists everything nbview keeps.
