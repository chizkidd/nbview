nbview

Read Jupyter notebooks from any public GitHub repo.

nbview is a fast nbviewer alternative that runs entirely in your browser, so there is no server to go down. Paste a GitHub repo, notebook link, gist or nbviewer link, or change nbviewer.org to nbview.org in the address bar and the same notebook opens here.

GitHub token

Opening notebooks never counts against GitHub's limits. Browsing folders does: 60 listings an hour without a token, 5,000 with one. A classic token with no scopes is enough. It's stored in this browser only.
